# Como publicar no GitHub Pages

1. Crie o repositório no GitHub.
2. Envie os arquivos do projeto para a branch principal.
3. No repositório, abra **Settings**.
4. Clique em **Pages**.
5. Em **Build and deployment**, escolha **Deploy from a branch**.
6. Selecione a branch **main** e a pasta **/ (root)**.
7. Clique em **Save**.
8. Aguarde o GitHub gerar o link do site.

## Estrutura usada neste trabalho
O arquivo principal é `index.html` na raiz do repositório, então a publicação deve apontar para a pasta raiz.
