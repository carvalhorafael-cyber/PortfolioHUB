# Texto para o LinkedIn

## Título do projeto
PortfolioHUB - Repositório de projetos acadêmicos e pessoais

## Descrição
Desenvolvimento de um repositório com organização de projetos acadêmicos e pessoais, uso de Git e GitHub para versionamento, criação de README, publicação com GitHub Pages e integração com LinkedIn.

Projeto acadêmico desenvolvido para demonstrar organização, versionamento e apresentação profissional na área de tecnologia.
