# Roteiro de apresentação (5 minutos)

Meu nome é Rafael Carvalho Oliveira. Neste trabalho, desenvolvi um repositório no GitHub para organizar meus projetos acadêmicos e pessoais.

A estrutura foi separada em pastas para facilitar a visualização e a manutenção dos arquivos. Criei uma página principal com apresentação profissional, além de projetos simples para demonstrar prática com HTML, CSS, JavaScript e uso de localStorage.

Também preparei documentação no README e em arquivos de apoio para explicar a organização do repositório. Depois, publiquei a página usando GitHub Pages, tornando o conteúdo acessível online.

Por fim, conectei o trabalho ao LinkedIn para reforçar meu perfil profissional e mostrar minha evolução na área de desenvolvimento.
